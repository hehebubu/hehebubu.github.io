# 마크다운 문법 예시

이 글은 자주 쓰는 마크다운 문법을 모아둔 참고용 글입니다.

## 제목 (Heading)

`#`의 개수로 제목의 크기를 정합니다.

```markdown
# 가장 큰 제목
## 중간 제목
### 작은 제목
```

## 글자 꾸미기

- **굵게**: `**굵게**`
- *기울임*: `*기울임*`
- ~~취소선~~: `~~취소선~~`
- `코드`: 백틱(`` ` ``)으로 감싸기
- ==하이라이트==: `==하이라이트==`

## 목록

순서 없는 목록은 `-`, 순서 있는 목록은 `1.`로 시작합니다.

- 사과
- 바나나
  - 들여쓰기하면 하위 항목

1. 첫 번째
2. 두 번째

## 할 일 목록

```markdown
- [ ] 아직 안 한 일
- [x] 완료한 일
```

- [ ] 아직 안 한 일
- [x] 완료한 일

## 링크

- 외부 링크: `[구글](https://google.com)` → [구글](https://google.com)
- 내부 링크 (다른 글로 연결): `[[첫-인사]]` → [[첫-인사]]

> [!tip] 내부 링크가 그래프 뷰를 만듭니다
> 글끼리 `[[제목]]`으로 연결하면 오른쪽 그래프 뷰에 연결선이 나타납니다.

## 인용문

```markdown
> 인용하고 싶은 문장
```

> 인용하고 싶은 문장

## 코드 블록

백틱 3개(```)로 감싸고 언어 이름을 적으면 색이 입혀집니다.

```python
def hello():
    print("안녕하세요!")
```

## 표

```markdown
| 이름 | 설명 |
| ---- | ---- |
| 사과 | 빨갛다 |
```

| 이름 | 설명 |
| ---- | ---- |
| 사과 | 빨갛다 |
| 바나나 | 노랗다 |

## 이미지

```markdown
![설명](이미지주소.png)
```

이미지 파일을 `content` 폴더 안에 넣고 파일명으로 불러올 수도 있습니다.
